# Customer Churn EDA

End-to-End Exploratory Data Analysis (EDA) on Customer Churn dataset using Python, Pandas, and Seaborn to identify key churn drivers.

## 📋 Overview

This project performs a comprehensive exploratory data analysis on a customer churn dataset to understand patterns, trends, and key factors that influence customer retention. The analysis uses Python data science libraries to clean, analyze, and visualize the data.

## 🎯 Objectives

- Understand the distribution of customer churn
- Identify key features driving customer churn
- Analyze customer demographics and behavior patterns
- Visualize relationships between features and churn
- Generate actionable insights for customer retention strategies

## 📊 Dataset

The analysis uses a customer churn dataset containing customer information and their churn status. The dataset includes various features such as:
- Customer demographics
- Service usage patterns
- Contract information
- Billing details

## 🛠️ Technologies & Libraries

- **Python 3.x**
- **Pandas** - Data manipulation and analysis
- **NumPy** - Numerical computing
- **Matplotlib** - Data visualization
- **Seaborn** - Statistical data visualization
- **Jupyter Notebook** - Interactive analysis environment

## 🚀 Getting Started

### Prerequisites

- Python 3.7 or higher
- Jupyter Notebook
- pip or conda package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Sahilbisht12/Customer_Churn_EDA.git
cd Customer_Churn_EDA
```

2. Install required dependencies:
```bash
pip install pandas numpy matplotlib seaborn jupyter
```

3. Launch Jupyter Notebook:
```bash
jupyter notebook
```

4. Open and run the notebooks to explore the analysis
